# NeuGrow demo: ten-minute feedback session

Open https://neugrow.vercel.app/ and use the demo account provided by the project
owner. This session is about how easy the app is to understand. Use fictitious
details; no camera or exercise performance is needed.

Please try these tasks in order. Say what you are looking for and tell us whenever
something is unclear. If you get stuck, note where before asking for help.

1. Sign in. On Garden, explain what you think the page shows and what you would
   do next.
2. Find the available exercises. Open a group, choose an available exercise and
   read its preparation instructions. Explain what you think you would need to
   do before starting. Stop before enabling the camera.
3. Find Progress. Look at Journal and Trends. Explain what each view tells you,
   including any empty state if this account has no sessions.
4. Find Profile. Locate where you would edit your name and where you would sign
   out. You do not need to change or save any profile details.
5. Return to Garden, then sign out through Profile. Open the demo homepage again
   and note whether it takes you to Login.

Afterward, send the project owner:

```text
Tester alias:
Date:
Device and browser:

Task results (without help / with help / blocked / not attempted):
1. Sign in and understand Garden:
2. Find an exercise and understand preparation:
3. Understand Journal and Trends:
4. Find profile actions:
5. Return home and sign out:

What was hardest to understand?
Where did you expect a different result? What happened instead?
What one change would make this easier?
Overall ease (1 = very difficult, 5 = very easy):
```

Do not include passwords or personal health information. A written description
of an issue is enough; screenshots are optional and should show demo data only.
